# 拓展 3：图形化界面 — 技术说明

## 技术选型

**HTML5 Canvas + 原生 JavaScript**，单文件自包含，零依赖。浏览器直接打开即可运行，无需编译、无需服务器。

## 核心功能

### 1. 通用图数据加载

- 内置**项目完整数据**（87 节点、26 边）作为默认展示
- 支持通过**文件选择器加载任意** `places.csv` / `roads.csv`（符合项目 schema）
- 前端直接解析 CSV（跳过表头、处理逗号分隔），与 C++ 的 CsvIO 逻辑对应

### 2. 混合布局引擎

采用**力导向 + 同心圆环**双层布局策略：

**连通分量检测**：仅遍历 `open` 状态的边，将全图分割为若干连通分量，按大小降序排列。

**主连通分量（力导向布局）**：
- 采用 **Fruchterman-Reingold** 力导向算法置于画布中央：
  - **节点间斥力**：所有节点对之间均存在斥力 $f_r = k^2 / d$，防止重叠
  - **边弹力**：每条边的两端之间存在吸引力 $f_a = d^2 / k$，保持连通
  - **温度冷却**：300 轮迭代，温度按 $t \cdot (1 - i/N)^{1.5}$ 衰减，加速收敛
  - 布局参数自适应节点数量，保证足够间距
- 完成后自动居中

**非连通分量（同心圆环）**：
- 计算主分量的实际包围半径 $R$
- 非连通分量从 **$R + 350$** 半径处开始，排布在外围同心圆上
- 每层 10 个分量，层间间距 200 单位
- 分量内节点沿圆弧均匀分布
- 渲染时以**虚线圆环**标识分层边界

### 3. 节点与边渲染

**节点**：
| 类别 | 颜色 |
|------|------|
| Sports_and_Entertainment | 红色 |
| Teaching_Research_and_Administration | 蓝色 |
| Dining_room | 橙色 |
| dormitory | 绿色 |
| Medical | 粉色 |
| other | 灰色 |

- 标签自动截断至 10 字符，字体随缩放自适应
- 悬停时节点放大并显示 tooltip 详情
- 选中/路径节点有红色光晕标识

**边**：
| 状态 | 线型 | 颜色 |
|------|------|------|
| open | 实线 | 绿色半透明 |
| closed | 虚线 | 红色 |
| 关键边 | 实线 | 橙色 + 加粗 |
| 最短路径 | 实线 | 红色 + 发光阴影 + 权重标注 |

已绘制的边通过 `Set` 去重，避免无向图双向边重复绘制。

### 4. 最短路径高亮

- Dijkstra 算法在前端实现（O(V²)，千节点以下流畅）
- 支持四种查询模式：
  - **DIST** — 最短距离（边权 = distance）
  - **TIME** — 最短时间（边权 = walk_time）
  - **TIMED_SHORTEST** — 时刻约束最短路径，输入 HH:MM 时刻 + DIST/TIME 子模式，Dijkstra 松弛时额外检查节点 `open_time ≤ time ≤ close_time`
  - **SHORTEST_K** — K 张加速券分层图最短路径，输入 K（0~10），每券将任一边耗时降为 `ceil(walk_time/3)`
- 仅走 `status=open` 的边（与 C++ 后端逻辑一致）
- 路径边以**红色粗线 + 发光阴影**高亮，每段标注权重；用券边以 ⚡ 标注加速后时间
- 路径节点以红色光晕标识
- 结果面板按对应命令格式显示完整信息（PATH/NODES/K_USED/FAST/时刻）

两种查询方式：
- 下拉菜单选择起终点 + 模式 + 参数 → 点击"查询路径"
- 点击画布上的节点（第一次=起点，第二次=终点，自动触发查询）

### 5. 关键节点 / 关键边标识

- 点击"关键节点/边"按钮触发分析
- 暴力连通分量重算（O(V·(V+E)) + O(E·(V+E))），与 C++ 后端 `FindCriticalNodesAndEdges` 逻辑完全一致
- **关键节点**：黄色虚线圆环标识
- **关键边**：橙色粗线标识
- 右侧面板实时显示列表

### 6. 连通分量可视化

- 点击"连通分量"按钮：
  - 各分量以**凸包（convex hull）半透明着色**区分
  - 非连通分量的同心圆环**虚线引导圈**同时显示
  - 面板显示分量总数

### 7. 视图交互

| 操作 | 效果 |
|------|------|
| 滚轮 | 缩放（0.12x ~ 6x），以鼠标位置为中心 |
| 拖拽 | 平移画布 |
| 双击 | 放大 1.35x，以双击点为中心 |
| 点击节点 | 第一次选起点，第二次选终点，自动查询 |
| 悬停节点 | 显示 tooltip 详情 |
| 重置视图 | 恢复默认缩放，居中显示全图 |

- 深色主题（#0a0e27 背景），Google Maps 风格
- 网格点背景辅助定位
- HiDPI 屏幕自适应（devicePixelRatio 正确计入渲染变换）

## 算法实现对照

| 算法 | C++ (Algorithm.cpp) | JS (graph_ui.html) |
|------|---------------------|-------------------|
| Dijkstra | priority_queue O((V+E)logV) | 线性扫描 O(V²) |
| 连通分量 | BFS + blocked 集合 | BFS + blocked 集合 |
| 关键节点/边 | 连通分量重算 | 连通分量重算 |
| 力导向布局 | — | Fruchterman-Reingold，300轮迭代 |
| 同心圆布局 | — | 自适应半径 + 分层圆环 |

前端算法的正确性可通过与 C++ 后端的输出对比验证。
