# 拓展 3：图形化界面 — 技术说明

## 技术选型

**HTML5 Canvas + 原生 JavaScript**，单文件自包含，零依赖。浏览器直接打开即可运行，无需编译、无需服务器。

## 核心功能

### 1. 通用图数据加载

- 内置 **case_01 样例数据**（6 节点、8 边）作为默认展示
- 支持通过**文件选择器加载任意** `places.csv` / `roads.csv`（符合项目 schema）
- 前端直接解析 CSV（跳过表头、处理逗号分隔），与 C++ 的 CsvIO 逻辑对应

### 2. 力导向自动布局

- 采用 **Fruchterman-Reingold 风格**的力导向算法：
  - **节点间斥力**：所有节点对之间均存在斥力（与距离平方成反比），防止节点重叠
  - **边弹力**：每条边的两端之间存在吸引力（与距离成正比），将连通节点拉近
  - **中心引力**：所有节点受指向画布中心的微弱引力，防止漂移
  - **阻尼衰减**：每轮迭代对位移施加 0.9 阻尼，加速收敛
- 200 轮迭代，maxMove < 0.1 时提前终止
- 点击"重新布局"可重新运行力导向算法
- 布局完成后节点可**手动拖拽微调**

### 3. 边连接区分 open / closed

| 状态 | 线型 | 颜色 |
|------|------|------|
| open | 实线 | 深绿色 |
| closed | 虚线 | 红色 |
| 关键边 | 实线 | 橙色 + 加粗 |
| 最短路径 | 实线 | 红色 + 发光阴影 + 权重标注 |

已绘制的边通过 `Set` 去重，避免无向图双向边重复绘制。

### 4. 最短路径高亮

- Dijkstra 算法在前端实现（O(V²)，千节点以下流畅）
- 支持 **DIST（距离）和 TIME（时间）双模式**切换
- 仅走 `status=open` 的边（与 C++ 后端逻辑一致）
- 路径边以**红色粗线 + 发光阴影**高亮，每段标注权重
- 路径节点以红色光晕标识
- 结果面板显示完整路径序列、每段详细信息

两种查询方式：
- 下拉菜单选择起终点 → 点击"查询路径"
- 点击画布上的节点（第一次=起点，第二次=终点，自动触发查询）

### 5. 关键节点 / 关键边标识

- 点击"关键节点/边"按钮触发分析
- 暴力连通分量重算（O(V·(V+E)) + O(E·(V+E))），与 C++ 后端 `FindCriticalNodesAndEdges` 逻辑完全一致
- **关键节点**：黄色虚线圆环标识
- **关键边**：橙色粗线标识
- 右侧面板实时显示列表

### 6. 其他交互功能

- **悬停 tooltip**：鼠标悬停节点显示完整信息（名称、类别、停留时间、开放时间）
- **连通分量着色**：不同分量用不同颜色半透明光晕标注
- **响应式布局**：侧边栏 + Canvas 自适应窗口
- **网格背景**：浅色网格辅助定位

## 算法实现对照

| 算法 | C++ (Algorithm.cpp) | JS (graph_ui.html) |
|------|---------------------|-------------------|
| Dijkstra | priority_queue O((V+E)logV) | 线性扫描 O(V²) |
| 连通分量 | BFS + blocked 集合 | BFS + blocked 集合 |
| 关键节点/边 | 连通分量重算 | 连通分量重算 |
| 力导向布局 | — | 斥力+弹力+中心引力+阻尼 |

前端算法的正确性可通过与 C++ 后端的输出对比验证。

## 运行方式

```bash
# Windows
start CampusNavigation/graph_ui.html

# macOS
open CampusNavigation/graph_ui.html

# Linux
xdg-open CampusNavigation/graph_ui.html
```

或浏览器直接打开文件。

默认展示 case_01 数据（6 节点），可通过文件选择器加载任意符合项目 schema 的 CSV 数据。
